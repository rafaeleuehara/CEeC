# Trabalhos para a disciplina de Computação Evolucionista e Conexionista

## Rede Neural: 
Foi feita uma arquitetura de rede neural feedforward de uma única camada com função de ativação sigmóide, com uma taxa de aprendizado de 10^-2. Além disso, foi utilizado backpropagation e métrica de regressão RMSE. O algoritmo tem como saída um gráfico mostrando o erro ao decorrer das épocas.

## Algoritmo Evolutivo:
Foi feito um algoritmo evolutivo de permutação para a solução do problema do caixeiro viajante, usando o método de seleção por torneio com uma taxa de sobrevivência de 50%, usando point crossover para reprodução e taxa de mutação de 5% com método de mudança de ordem. O algoritmo tem com saída a evolução do fitness ao decorrer das épocas.
